# assets/

Сюда нужно положить файл печати/подписи:

- **`stamp.jpg`** — скан подписи генерального директора + печати ООО «Ставропольгеодезия»
  (тот самый, ~352×275, который раньше вставляли в письмо вручную).

Имя файла строго `stamp.jpg`. Если нужно другое имя/формат — поправьте `STAMP_PATH`
в [`../letter_render.py`](../letter_render.py).

Пока файла нет, `send_letter` всё равно соберёт PDF и отправит письмо, но **без печати**
(блок `<img>` в шаблоне просто не выводится). Положите `stamp.jpg` и закоммитьте —
печать появится на бланке автоматически.
